Week 3 Data Preparation Note

CRS Chosen: EPSG:32632 (WGS 84 / UTM zone 32N). 
Why: The original data was in EPSG:4326 (geographic degrees). I reprojected it to UTM zone 32N because it is a projected coordinate system that uses meters, which is necessary for accurate area and distance calculations for the Maiduguri study area.

Reprojection and Clipping:
I reprojected the original Nigeria ward boundaries layer to EPSG:32632. I then clipped the reprojected layer using the Maiduguri layer as the overlay boundary to isolate my study area.
